# Product Decision Records (PDR) – Index

Für **nichttechnische** Produktentscheidungen: Ziele, Prioritäten, Scope-Cuts,
Zielgruppen-Fokus. **Technische** Entscheidungen gehören in ADRs
([../adrs/](../adrs/README.md)), nicht hierher.

## Wann ein PDR?

Wenn eine Produkt-/Priorisierungsentscheidung tragend ist und sonst nur im Chatverlauf
oder in einer Issue-Diskussion läge (z. B. „Warum ist #44 der einzige v0.2-Feature-Fokus?",
„Warum #49 vor #48?"). Format analog zum [ADR-Template](../../templates/adr-template.md):
Kontext, Optionen, Entscheidung, Nicht-Ziele, Konsequenzen – aber produktseitig.

## Aktuelle PDRs

_Noch keine._ Bestehende Produktentscheidungen sind derzeit in der
[roadmap.md](../roadmap.md) (Portfolio-Cut, Backlog-Regel, Reihenfolge) und im
[Release Charter v0.2](../release-charters/v0.2.md) festgehalten. Ein eigenständiges PDR
wird angelegt, sobald eine Entscheidung von diesen Dokumenten abweicht oder sie präzisiert.
