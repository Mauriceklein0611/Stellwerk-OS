# Release Charter · v0.2 – Erster echter Agent

> Aktiver Meilenstein. Deckungsgleich mit [roadmap.md §Teil 5](../roadmap.md). Nach
> Release wird dieses Dokument mit Ist-Ergebnis geschlossen (`superseded`/`frozen`),
> nicht gelöscht.

## Release-Ziel

Ein PO erzeugt per Klick einen Projekt-Draft von einem **echten LLM** – end-to-end als
generischer Plattform-Slice `UI → BFF → Agent Runtime → Gateway → Telemetrie`. Erste
registrierte Definition: **`pms.draft@1.0.0`**.

## Zielgruppen

PO (echte Hilfe statt Mock), Mod-Dev (Runtime-Grenze bewiesen), prüfende Person
(Nachvollziehbarkeit), Besucher (ehrlicher Slice).

## Problem & erwartetes Ergebnis

Heute ist der Agent ein Mock ([apps/pm-studio/src/lib/mock-agent-service.ts](../../../apps/pm-studio/src/lib/mock-agent-service.ts)),
es gibt keine Core-Runtime und Kosten sind nicht als real/simuliert/unbekannt
unterscheidbar. Ergebnis: ein nachvollziehbarer, kostentransparenter, schema-validierter
Run über die generische Runtime.

## Scope

- **v0.2-A Foundation-Gate** (blockierende Vorphase, E1): #54 Datenmigration, #55
  Container-Build/Start + Laufzeitmatrix, #56 Prod-Fail-Fast, #57 `/readyz`-Migrationsstand,
  #58 hermetischer Ollama-Provider, #59 Root-Doku + Playwright-Pflicht-Smoke.
- **ADR-011–015** angenommen (#53, ✅ gemergt).
- **#44** – einziger Feature-Fokus: `pms.draft@1.0.0`, idempotente Run-Erstellung,
  BFF→Runtime→Gateway, schema-validierter Output (max. 1 Repair-Retry), verlinkte
  Calls/Kosten, ehrliche Fehlerzustände, Reconciler.
- **#60 (E3.1)** – Kostenprovenienz (`pricing_status`/`currency`/`price_version`,
  unbekannt = NULL).

## Nicht-Ziele (in #44/v0.2)

Keine Gates, Workflows, Artefakt-Chats (→ v0.3); kein OIDC/Keycloak (→ v0.4); keine
Cloud/Azure (→ v0.5); kein separates PMS-Backend/SQLite (ADR-011); kein Provider-SDK
außerhalb des Gateways (ADR-006); **kein stiller Mock-Fallback**; kein Compliance-Audit-Claim
(`run_events` = Run-Historie bis v0.4); kein PMS-Seed in Core-Migration; kein SSE/Streaming.

## Abhängigkeiten & Reihenfolge

ADR-011–015 (✅) → v0.2-A-Gate (#54–59) grün **und** #60 (Kostenfelder) → **#44** als
letzter Schritt. Danach v0.2 veröffentlichen, **erst dann** v0.3 schneiden.

## Risiken

R1 (Scope), R3 (LLM-Qualität), R6 (Payload-Daten), R9 (Injection – v0.2: keine Tools),
R12 (Doku-Drift). Siehe [risk-register.md](../risk-register.md).

## Kapazitätsannahme

Ein-Personen-Projekt + KI-Agenten. Keine Wochen-Termine ohne dokumentierte Annahme,
Konfidenz und Reviewdatum – kein versteckter Liefervertrag.

## Erfolgskriterien (Definition of Done)

- [ ] `pms.draft@1.0.0` läuft UI→BFF→Runtime→Gateway mit **Stub deterministisch in CI**
      und **Ollama** im dokumentierten lokalen Release-Smoke.
- [ ] Run-Erstellung **idempotent** (gleicher Key+Payload → derselbe Run; anderer Payload → 409).
- [ ] übergroße Eingabe wird **abgelehnt statt gekürzt**; Output **schema-validiert** (max. 1 Repair-Retry).
- [ ] Kostenprovenienz korrekt (**unbekannt = NULL, nie 0**); `service`/`user_context` getrennt.
- [ ] **kein stiller Mock-Fallback**; Fehlerzustände `schema_error`/`provider_error`/`core_unavailable` getestet.
- [ ] Reconciler markiert nur alte `running`-Runs als `failed(interrupted)`.
- [ ] v0.2-A-Gate grün (beide Images bauen+starten, `/readyz` mit Migrationscheck, Prod-Fail-Fast, hermetischer Ollama, Playwright-Pflicht-Smoke).
- [ ] `make contracts` driftfrei; #44 geschlossen; **beide Images in GHCR**.

## Release-Nachweise

CI (`ci-ok`) grün inkl. Container-Smoke und kritischem Playwright-Pfad; dokumentierter
lokaler Ollama-Release-Smoke; `CHANGELOG.md`-Block + GitHub Release; dieses Charter mit
Ist-Ergebnis und `outcomes.md`-Nachweis (O1–O3) geschlossen.

## Abbruch-/Verschiebekriterien

Kippt das v0.2-A-Gate wiederholt oder frisst ein Foundation-Fix die WIP-Grenze, wird
#44 verschoben, **nicht** verwässert. Cancel und typisierter Business-Kontext werden im
**v0.3**-Schnitt bewertet, nicht nachträglich in #44 gedrückt.
