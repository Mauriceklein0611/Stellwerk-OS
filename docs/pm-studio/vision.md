# Vision

## Zielbild

Eine moderne, lokal lauffähige Projektmanagement-Plattform, die sich optisch an Linear, Jira und ClickUp orientiert, aber einen eigenen Fokus hat: **Projektmanagement mit KI-Agenten**.

Der Nutzer gibt eine Projektidee ein. Spezialisierte Agenten überführen sie Schritt für Schritt in einen vollständigen Projektentwurf:

```
Projektidee
 → Projektentwurfs-Agent
 → Requirements-Agent
 → Scrum-Agent (inkl. Aufwandsschätzung)
 → Product-Owner-Agent
 → Risiko-Agent
 → Review-Agent
 → Sprint- & Aufgabenboard
(später: Test-, CI/CD-, Qualitäts-, Retro-Agent)
```

Jeder Agent hat eine klare Rolle, verarbeitet die strukturierten Ergebnisse des Vorgängers und erzeugt strukturierte Ergebnisse für den Nachfolger.

## Persönliche Ziele

- Moderne Frontend-Entwicklung lernen (Next.js, TypeScript, Komponentenarchitektur)
- Web-App-Architektur verstehen (Frontend ↔ API ↔ Agenten-Backend)
- Scrum, Product Ownership und agile Planung praktisch vertiefen
- Agenten-Orchestrierung verstehen (LangGraph, strukturierte Outputs)
- Lokale KI auf RTX 3060 Ti (8 GB VRAM) produktiv einsetzen
- GitHub-Portfolio-Projekt für Bewerbungen (PM, Scrum Master, PO, AI PM, AI Consultant)

## Leitplanken

- So lokal wie möglich, keine kostenpflichtigen APIs
- Open Source bevorzugt, spätere Veröffentlichung möglich
- Kleine, testbare, dokumentierte Bausteine
- Lernen > Geschwindigkeit: Jeder Schritt soll nachvollziehbar sein

## Langfristvision

Ein System, das Projektmanagement, Scrum, Entwickler-Workflows, Tests, Reviews, CI/CD und Retrospektiven mit konfigurierbaren Agenten-Workflows (eigener Workflow-Builder) in einer Plattform verbindet.
