## Teil F – Audit-Fazit & Route-Matrix

**Urteil:** Technisch deutlich weiter als ein Prototyp, aber als vollständiges
PM-Tool noch nicht UI-abgeschlossen – teilweise abschließbar, nicht release-reif
als kompletter PM-Workflow.

Größte Blocker (Stand Snapshot):
1. Sprint Review/Retro fehlt komplett. *(inzwischen erledigt – PR #69)*
2. Story-Completion fachlich zu optimistisch (≥1 terminaler Task statt alle).
3. Agent-Pipeline UI-seitig unvollständig (PO/Review ohne Agent/Run).
4. Lifecycle-Aktionen fehlen/unsicher (kaum Edit/Delete, kein Confirm/Undo/Toast).
5. Release-, Reporting-, Dependency- und Activity-Funktionen zu dünn.

| Bereich | Status | Einschätzung |
|---|---|---|
| `/` Dashboard | teilweise | Reale Kennzahlen, aber Reporting oberflächlich. |
| `/ideas/new` | gut | Erstellen ok, kein voller Idea-Lifecycle. |
| `/projects` | teilweise | Liste/Details gut, Edit/Delete fehlen. |
| `/projects/[id]` | teilweise | Backlog/StoryTasks stark, Pipeline/Done-Semantik problematisch. |
| `/agents` | teilweise | Gute Mock-Übersicht, kein echter Agentenbetrieb. |
| `/agents/[id]` | teilweise | Runs sichtbar, entkoppelt von Projektentscheidungen. |
| `/workflows` | teilweise | Eher Simulator als Builder. |
| `/board` | gut/teilweise | Stärkstes Modul; Delete/Undo/Feedback fehlen. |
| `/sprints` | teilweise* | Planung vorhanden; Review/Retro inzwischen ergänzt. |
| `/releases` | teilweise | Sprint-Generierung ja, echtes Release-Management fehlt. |
| `/team` | teilweise | Assignee-Aufräumen bei Löschung fehlt (usePeopleStore.ts:35). |
| `/settings` | gut | Für aktuellen Scope ausreichend. |

**Wichtige Details:** CommandBar ist nur Navigation; Navigation mischt
Englisch/Deutsch und gruppiert `Team` unter `Agents`; TaskDialog ohne echten
Delete/Archive-Pfad; Sprint-Zuweisung nur über Stories (Tasks ohne Story wirken
still blockiert); Releases brauchen Status/Scope/Risiko/Notes/Timeline; die
Agentenidee ist in der Doku reifer als in der UI (fehlend: persistente HITL-
Entscheidungen, Artefaktversionen, nachvollziehbare Approvals).

**Qualitäts-Gate (Snapshot):** lint grün (3 Warnungen TanStack/React-Compiler),
`tsc` grün, test grün (69 Dateien / 314 Tests → inzwischen 71 / 331), build grün
(braucht Netz für Next/SWC/Fonts), e2e 12/12.
